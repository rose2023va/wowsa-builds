# WOWSA Staff Hub - Build Knowledge Base

This is the source of truth for the internal staff hub project: a private admin site + AI knowledge access for WOWSA staff (Rose, Quinn, later customer service).

## Structure

- `ROADMAP.md` - phased plan for the whole project, meant to be updated as decisions change. Read this first in any new session.
- `DESIGN-SYSTEM.md` - visual design tokens pulled from Quinn's Lovable landing pages (e.g. freestyle-biomechanics.openwaterswimming.com), to keep this site visually consistent with the rest of WOWSA's Lovable builds.
- `WORDPRESS-MCP-SETUP.md` - step-by-step setup for connecting Claude Code to openwaterswimming.com's WordPress/WooCommerce data via MCP (posts, pages, products, orders).
